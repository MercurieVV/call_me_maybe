Write code as a multi-line quoted heredoc (always works, no quoting issues):
  scala_repl_add <<'SCALA'
  ...several lines of Scala...
  SCALA
The bridge starts by itself; the first call loads the index (~15 s for a big root). State (val/def) is kept
between calls, so build on earlier results instead of recomputing. `run` is an alias of the default eval.
Compose the whole chain in one program and println only the compact result. Filter, group and sort in Scala;
never pipe, redirect to files, or call grep/rg/sed/awk.

Examples:
  // who uses a class/method, grouped by file
  usagesOf("OauthTokenService", 500).groupBy(_.takeWhile(_ != ':')).view.mapValues(_.size).toSeq.sortBy(-_._2).foreach(println)
  // find a symbol, then its owner chain and reference count
  findSymbols("^getOAuthToken$").foreach(i => println((i.symbol, semanticIndex.ownerChain(i.symbol), semanticIndex.occurrencesOf(i.symbol).size)))
  // config / non-Scala text in one repo, with line numbers
  corpus.filter(d => d.path.startsWith("P-Foo/") && d.path.endsWith(".conf")).foreach(d =>
    d.lines.zipWithIndex.filter(_._1.contains("proxy")).foreach((l, i) => println(d.path + ":" + (i + 1) + ": " + l.trim)))
  // text hits restricted to a path and extension; hits in Scala files show [in Owner.name] - pass that name to usagesOf
  searchText("(?i)proxy", 100, pathPrefix = "P-Foo/", exts = Set("yml", "conf")).foreach(println)
  // matches with surrounding lines, and a file slice
  ctx("SESSION_API", pathPrefix = "P-Foo/", before = 2, after = 5)
  show("sessions-api/reference.conf", 1, 60)
  // nearest definition for any line you found yourself
  enclosing("P-Foo/src/main/scala/com/x/Bar.scala", 120)

Notes: os (os-lib), Try, Using and CollectionConverters.* are imported. semanticIndex is lazy and covers the compiled
SemanticDB of every repo under the root (SemanticIndex: symbols, occurrencesOf, info, ownerChain, ...).

Rules:
  Use semanticIndex/findSymbols/usagesOf for Scala code questions (who calls/uses/builds X) BEFORE text search.
  Text search (corpus/searchText/ctx) is for config, string literals and keys; then switch to usagesOf on the
  enclosing symbol. git worktrees (<root>/worktrees) are excluded from corpus and usagesOf (usagesOf(..., worktrees = true)).
  Do not use os.proc grep/rg/find/sed/awk.
  Repo has no SemanticDB? Do not text-scan: run `scala_repl_add index <repo-dir>` (sbt compile with SemanticDB,
  ~5 min, run it in async mode), then `scala_repl_add stop`; the bridge restarts on the next call.
  `index --force` rebuilds after source changes.
